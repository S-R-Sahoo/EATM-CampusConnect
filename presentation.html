11 / SECURITY MODEL

Enterprise Security: Authentication vs Authorization

🔐 Authentication (Who You Are)

  • ✔ Supabase Auth Engine: Encrypted JWT-backed sessions with secure token rotation.
  • ✔ Role Claim Tokens: Institutional role (Student, Faculty, Admin) embedded in session.
  • ✔ Client Route Guards: Protected routing components preventing unauthorized access.

🛡️ Authorization (What You Can Do)

  • ✔ PostgreSQL RLS: Security rules enforced directly inside the database kernel.
  • ✔ Multi-Tenant Isolation: Users can query and modify only permitted records.
  • ✔ Private Message Isolation: Direct messages inaccessible to non-participants.

12 / DATABASE DESIGN

Relational Database Schema (12 Tables)

👤 Identity & Profiles Domain

Tables: profiles, auth.users

User roles, department, semester, bio, profile avatar, and technical skills catalog.

💬 Real-Time Messaging Domain

Tables: conversations, messages

Direct/group conversation rooms, message text, media attachments, and audio waveform data.

🌐 Campus Social Feed Domain

Tables: posts, comments, likes, connections

Feed posts, code snippets, user reactions, timestamps, connection requests, and threaded comments.

📚 Academic Resources Domain

Tables: study_materials, communities, events

Department/semester study notes, question banks, symposium events, and RSVP registers.
